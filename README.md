# 🏥 MediCare Hospital - Patient Management System

A lightweight, modern, single-page web application built with **React**, **HTML5**, and **CSS3** for managing hospital operations, tracking bed occupancy, and monitoring department analytics in real-time.

---

## ✨ Features

* **📊 Dashboard Analytics**: Live overview of total, admitted, and discharged patient counts.
* **🛏️ Live Bed Occupancy Tracker**: Real-time progress bar tracking total bed usage against hospital capacity.
* **📈 Department Analytics Chart**: Visual representation of patient distribution using Chart.js.
* **👨‍⚕️ On-Duty Doctor Roster**: Widget tracking active shift schedules and doctor statuses (On Duty, In Surgery, Off Duty).
* **👥 Complete Patient CRUD**:
  * **Create**: Register new patients with assigned doctors, department, and admission details.
  * **Read**: View comprehensive patient records in a clean modal view.
  * **Update**: Edit existing patient data seamlessly.
  * **Delete**: Remove outdated or duplicate records with a confirmation prompt.
* **🔍 Search & Filter**: Filter patient records by department, status, or search directly by name or ID.
* **📥 Export to CSV**: One-click download of current patient logs into a standard CSV file.
